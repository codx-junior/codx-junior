feat: autonomous profiles with self-scheduling

Adds an initiative layer on top of profiles. A profile may carry an
autonomy block (mode, board, interval, budget) and a background worker
wakes it on schedule, creates its agent board when missing and runs
the resulting task card. Agents inherit the codx-junior toolset, so
they can create and follow up their own tasks.

Chat gains wake_at, so a follow-up can be scheduled. task_manager
.to_wake_at normalizes +2d, "6 hours", plain dates and ISO strings.
project_manager and the new autonomy_management tool expose it, which
is what lets an agent schedule its next check ("look again in two
days").

New modules: autonomy/{constants,models,prompts,service,store,worker}
plus api/autonomy.py router (status, agents, enable, disable, wake,
schedule, run), tools/autonomy_tools.py and the docs page
docs/features/autonomous-agents.md.
